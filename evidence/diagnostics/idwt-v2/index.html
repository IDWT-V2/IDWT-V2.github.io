idwt-v2.py

Calculation record

Executable mathematics for IDWT V2.

This program collects calculations established in the V2 physics
modules. Its first section verifies the simplex counting theorem and tests
whether the observed particle-mass hierarchies recover their proposed integer
depths after all common sector scales have been removed or re-optimized.

Run from the repository root with:

python3 experiments/idwt-v2.py

The program uses the Python standard library. Experimental values provide the
comparators. Each printed optimization fits one common scale to every member
of a sector.
