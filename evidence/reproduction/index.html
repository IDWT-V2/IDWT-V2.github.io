Reproducing the calculations

This directory holds executable research separately from the readable modules and research notes. Python helper modules remain alongside the diagnostics that import them. See the diagnostic catalog for each calculation's scope and the links to its derivation.

Run these commands from the repository root:

python3 -B experiments/idwt-v2.py
OPENBLAS_NUM_THREADS=1 python3 -B experiments/run_checks.py --skip-continuation --jobs 2
node experiments/tests/orbit-renderer.test.cjs

The selected suite includes the saved-state refinement audit but explicitly excludes two expensive continuation searches. Omit --skip-continuation to include them. Individual scripts can also be run directly.

Recorded evidence

results/ contains the existing numerical reports, input candidates, and frozen protocols. They were moved without changing their bytes. Historical logs may retain old workspace paths: those describe past runs, not current dependencies. Save each new run separately; do not rewrite earlier evidence to match a new outcome.

The cylindrical refinement check automatically saves each completed report in results/two-path-study/ with the current UTC date and time in its filename, for example cross-method-verification-20260908T074500.123456Z.json. It preserves existing reports, even if two runs generate the same timestamp. Use --output-dir DIRECTORY to choose another destination, --no-save for a read-only run, or --output FILE to choose an explicit new filename.

Diagnostics locate their bundled inputs relative to their own script file, not a neighboring project or a fixed machine path. Python requires the scientific packages used by each calculation, including NumPy, SciPy, SymPy, and mpmath. The knowledge-base validator additionally uses PyYAML; the renderer test uses Node.js built-ins.
