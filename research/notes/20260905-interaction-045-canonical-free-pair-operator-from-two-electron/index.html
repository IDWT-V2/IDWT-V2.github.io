45. Canonical free-pair operator from two electron complex structures

To test whether a free electron pair can generate the locking map QQQ without importing a nucleus-selected 3+33+33+3 split, construct the most immediate pair operator from the two orthogonal complex structures,

R12=−J1J2. \boxed{ R_{12}=-J_1J_2. } R12​=−J1​J2​.​

Since

JiT=−Ji,Ji2=−I6, J_i^T=-J_i, \qquad J_i^2=-I_6, JiT​=−Ji​,Ji2​=−I6​,

one has

R12TR12=I6, R_{12}^TR_{12}=I_6, R12T​R12​=I6​,

so R12∈SO(6)R_{12}\in SO(6)R12​∈SO(6) for the explicit electron-sector realization.

Using the diagonal-SU(4)SU(4)SU(4) canonical pair

Z1=e1,Z2=cos⁡θ e1+sin⁡θ e2, Z_1=e_1, \qquad Z_2=\cos\theta\,e_1+\sin\theta\,e_2, Z1​=e1​,Z2​=cosθe1​+sinθe2​,

the exact gamma-matrix calculation gives

R12=I2⊕R(2θ)⊕R(−2θ), \boxed{ R_{12}=I_2\oplus R(2\theta)\oplus R(-2\theta), } R12​=I2​⊕R(2θ)⊕R(−2θ),​

up to ordering of the real basis, where R(φ)R(\varphi)R(φ) is a real planar rotation.

Equivalently,

tr⁡R12=2+4cos⁡(2θ), \boxed{ \operatorname{tr}R_{12}=2+4\cos(2\theta), } trR12​=2+4cos(2θ),​

and the characteristic polynomial is

χR12(λ)=(λ−1)2(λ2−2cos⁡(2θ)λ+1)2. \boxed{ \chi_{R_{12}}(\lambda) =(\lambda-1)^2 \left(\lambda^2-2\cos(2\theta)\lambda+1\right)^2. } χR12​​(λ)=(λ−1)2(λ2−2cos(2θ)λ+1)2.​

Thus, for generic pair separation, the real six-dimensional representation has a canonical decomposition

R6=Efix(2)⊕Erot(4). \boxed{ \mathbb R^6 =E_{\rm fix}^{(2)}\oplus E_{\rm rot}^{(4)}. } R6=Efix(2)​⊕Erot(4)​.​

In a convenient canonical basis the four-dimensional rotating block can be displayed as two planar rotations R(2θ)⊕R(−2θ)R(2\theta)\oplus R(-2\theta)R(2θ)⊕R(−2θ), but that planar 2+22+22+2 refinement is not itself uniquely selected by the pair invariants. The invariant content is the fixed two-plane plus the active four-space.

45.1 Consequence for the free-pair locking problem

This is a genuine pair-defined frame structure: it depends only on (J1,J2)(J_1,J_2)(J1​,J2​) and therefore requires no external nucleus or observer-selected 3+33+33+3 decomposition.

However, it is not the previously used

R3⊕R3 \mathbb R^3\oplus\mathbb R^3 R3⊕R3

split. The generic free pair naturally gives the invariant split

2+4, \boxed{2+4,} 2+4,​

not 3+33+33+3. A displayed 2+2+22+2+22+2+2 block form is basis-dependent inside the active four-space.

Therefore the exact 3+33+33+3 Schur-lock model cannot yet be promoted to an SU(4)SU(4)SU(4)-invariant free-electron theorem merely by replacing the nucleus with the second electron.

This is an important negative result: the pair geometry itself selects canonical planes, but their dimensions differ from the nucleus-relative decomposition.

45.2 Relation to the single pair invariant

The spectrum of R12R_{12}R12​ is completely determined by the Fubini--Study separation θ\thetaθ, hence by

ν=cos⁡2θ. \nu=\cos^2\theta. ν=cos2θ.

The canonical relative rotation angle is 2θ2\theta2θ, and

tr⁡R12=2+4(2ν−1)=8ν−2. \operatorname{tr}R_{12} =2+4(2\nu-1) =8\nu-2. trR12​=2+4(2ν−1)=8ν−2.

Using

CJ=4ν−13, C_J=\frac{4\nu-1}{3}, CJ​=34ν−1​,

one gets

tr⁡R12=6CJ. \boxed{ \operatorname{tr}R_{12}=6C_J. } trR12​=6CJ​.​

This is consistent with

CJ=−16tr⁡(J1J2)=16tr⁡R12. C_J=-\frac16\operatorname{tr}(J_1J_2) =\frac16\operatorname{tr}R_{12}. CJ​=−61​tr(J1​J2​)=61​trR12​.

45.3 Revised free-electron question

The appropriate free-pair problem is therefore not immediately

h=QTu h=Q^Tu h=QTu

for two three-planes. Instead it is whether the master interaction dynamically correlates the three pair-defined two-planes supplied by R12R_{12}R12​ in such a way that the observer's resolved three-dimensional motion becomes correlated with the unresolved directions.

The nucleus-induced 3+33+33+3 structure remains valid for bound electron--nucleus systems. The free electron pair has a different canonical symmetry reduction and must be treated separately.
