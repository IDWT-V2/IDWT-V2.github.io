55. Candidate scan for a dynamically selected mixed frame

Several V2-native candidates were tested for a mixed orientation-selecting block that could select a beam-relative frame link QQQ without inserting it by hand.

55.1 Pair commutator

The first candidate is

Fpair=[J1,J2]. F_{\rm pair}=[J_1,J_2]. Fpair​=[J1​,J2​].

It is exactly related to the antisymmetric part of

R=−J1J2 R=-J_1J_2 R=−J1​J2​

by

[J1,J2]=−2 R−RT2. [J_1,J_2]=-2\,\frac{R-R^T}{2}. [J1​,J2​]=−22R−RT​.

In the canonical test pair and a fixed laboratory 3+33+33+3 split, its mixed 3×33\times33×3 block has generic rank one and vanishes as the pair approaches projective coincidence.

Therefore

the tested rank-one mixed block does not determine a full SO(3) orientation. \boxed{ \text{the tested rank-one mixed block does not determine a full }SO(3)\text{ orientation.} } the tested rank-one mixed block does not determine a full SO(3) orientation.​

This is a result for that test pair and split, not a universal mixed-rank theorem for all placements of the pair relative to the laboratory split. The intrinsic pair decomposition is 2+42+42+4.

55.2 Single orbital bivector

A natural scattering object is the relative orbital bivector

L=x∧p. L=x\wedge p. L=x∧p.

Its mixed block is

EL=xOpHT−pOxHT. E_L=x_Op_H^T-p_Ox_H^T. EL​=xO​pHT​−pO​xHT​.

This is a difference of two rank-one matrices, so

rank⁡EL≤2. \boxed{ \operatorname{rank}E_L\le2. } rankEL​≤2.​

A single nondegenerate orbital bivector can select a full SO(3)SO(3)SO(3) frame relation: its rank-two mixed tensor has a unique orientation-preserving Procrustes completion (Section 99).

55.3 Two generic simple bivectors

A sum of two independent simple bivectors can generically produce

rank⁡E=3. \operatorname{rank}E=3. rankE=3.

Explicit random tests gave nonzero determinants in generic samples. Therefore rank three is not forbidden once more than one independent scattering two-plane participates.

However, an arbitrary sum of two bivectors has no unique V2-native prescription yet, so this observation establishes possibility rather than a preferred construction.

55.4 Scattering-triad candidate

A sufficient, nonminimal candidate is built from relative momentum and impact data in each half of the beam-adapted split.

Let

pO,bO∈O,pH,bH∈H, p_O,b_O\in O, \qquad p_H,b_H\in H, pO​,bO​∈O,pH​,bH​∈H,

and define the oriented normal directions

nO=pO×bO,nH=pH×bH. n_O=p_O\times b_O, \qquad n_H=p_H\times b_H. nO​=pO​×bO​,nH​=pH​×bH​.

Form the oriented scattering-frame matrices

Os=[pO  bO  nO],Hs=[pH  bH  nH]. O_s=[p_O\;b_O\;n_O], \qquad H_s=[p_H\;b_H\;n_H]. Os​=[pO​bO​nO​],Hs​=[pH​bH​nH​].

The mixed tensor

Etri=OsHsT=pOpHT+bObHT+nOnHT \boxed{ E_{\rm tri} =O_sH_s^T =p_Op_H^T +b_Ob_H^T +n_On_H^T } Etri​=Os​HsT​=pO​pHT​+bO​bHT​+nO​nHT​​

has determinant

det⁡Etri=∣pO×bO∣2∣pH×bH∣2. \boxed{ \det E_{\rm tri} =|p_O\times b_O|^2 |p_H\times b_H|^2. } detEtri​=∣pO​×bO​∣2∣pH​×bH​∣2.​

Therefore it is generically full rank whenever momentum and impact vectors are nonparallel in both three-planes.

This is stronger than a rank-one source, but a rank-two orbital source already suffices for orientation (Section 99).

55.5 Exact oriented-frame limit

If the two scattering triads are orthonormal and oriented, then

Os,Hs∈SO(3), O_s,H_s\in SO(3), Os​,Hs​∈SO(3),

and

Etri=OsHsT∈SO(3). \boxed{ E_{\rm tri}=O_sH_s^T\in SO(3). } Etri​=Os​HsT​∈SO(3).​

Thus in this limit the mixed tensor is itself exactly the relative rotation carrying the hidden scattering frame into the observed scattering frame.

This gives a non-circular candidate for

Q=OsHsT. \boxed{Q=O_sH_s^T.} Q=Os​HsT​.​

Unlike the earlier hand-chosen FmixF_{\rm mix}Fmix​, this QQQ is constructed from collision data.

55.6 Generic nonorthogonal triads

For raw nonorthogonal vectors, EtriE_{\rm tri}Etri​ remains full rank and transforms covariantly,

Etri⟼ROEtriRHT. E_{\rm tri} \longmapsto R_OE_{\rm tri}R_H^T. Etri​⟼RO​Etri​RHT​.

Its polar factor therefore transforms as

QE⟼ROQERHT. Q_E \longmapsto R_OQ_ER_H^T. QE​⟼RO​QE​RHT​.

Numerical tests confirm covariance to machine precision.

However, for generic nonorthogonal triads,

polar⁡(OsHsT)≠polar⁡(Os)polar⁡(Hs)T \operatorname{polar}(O_sH_s^T) \ne \operatorname{polar}(O_s) \operatorname{polar}(H_s)^T polar(Os​HsT​)=polar(Os​)polar(Hs​)T

exactly. The discrepancy in representative random samples was of order 5×10−25\times10^{-2}5×10−2 to 1.7×10−11.7\times10^{-1}1.7×10−1 in Frobenius norm.

Therefore metric weighting in the unnormalized triads matters.

The clean construction is consequently to form the orthonormalized oriented scattering frames first and then take their relative rotation.

55.7 Degenerate limit

If

pO∥bO p_O\parallel b_O pO​∥bO​

or

pH∥bH, p_H\parallel b_H, pH​∥bH​,

then

det⁡Etri=0. \det E_{\rm tri}=0. detEtri​=0.

The scattering state then fails to define a complete oriented three-frame, so no unique full QQQ can be extracted from these data alone.

This is physically sensible: a strictly head-on/zero-impact configuration has enhanced rotational symmetry and does not carry enough directional information to select all three axes.
