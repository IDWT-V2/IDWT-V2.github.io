Required continuation method

First correct candidates using integration accuracy independently adequate for the desired closure tolerance. Pseudo-arclength continuation is a candidate improvement, not a guaranteed remedy. Multiple-shooting nodes can be placed at the six cylindrical-support encounters, where the profile changes curvature most rapidly. The existing fixed SO(4)SO(4)SO(4) source chart already uses self-dual and anti-self-dual two-spheres and removes the two Casimir-normal directions. Time phase, amplitude/arclength, and the remaining visible/unobserved rotation gauges must also be fixed explicitly. Only after reaching h=1h=1h=1 should the full reciprocal moving-nucleus system be continued from the fixed-centre solution and its Floquet multipliers computed.
