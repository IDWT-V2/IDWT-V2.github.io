49. Beam-adapted 3+33+33+3 frame links recover the pair invariant exactly

The free unordered pair does not itself select the laboratory 3+33+33+3 split. A beam experiment, however, supplies an observed three-plane and its orthogonal complement. Once both electron complex structures are written relative to that same split, the pair invariant has an exact frame-link interpretation.

On the locked 3+33+33+3 orbit, write

J(Q)=(0Q−QT0),Q∈SO(3). J(Q) = \begin{pmatrix} 0&Q\\ -Q^T&0 \end{pmatrix}, \qquad Q\in SO(3). J(Q)=(0−QT​Q0​),Q∈SO(3).

49.2 Consequence for collision correlation

The beam-selected 3+33+33+3 split is additional scattering data, not an invariant supplied by the static unordered pair. Once that physically supplied split exists, however, the relative electron-sector geometry and the mismatch of the two visible-hidden frame links are no longer separate quantities:

projective pair separation⟺relative SO(3) link mismatch. \boxed{ \text{projective pair separation} \Longleftrightarrow \text{relative }SO(3)\text{ link mismatch}. } projective pair separation⟺relative SO(3) link mismatch.​

Hence a pair interaction that reduces Fubini--Study separation also reduces the mismatch between the two beam-adapted QQQ links automatically.
