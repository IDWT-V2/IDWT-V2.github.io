Define what is random before scoring a match

A numerical coincidence acquires a tail probability only after specifying a null distribution and a complete scoring procedure. For a statistic TTT whose larger values mean a closer match, the null tail is

Repeat the whole procedure in simulation

If a numerical analysis searches over depths, index assignments, formulas, anchors, tolerances, or subsets, apply that same search to each simulated null dataset. For example, if the reported statistic is the best score T=max⁡m∈MTmT=\max_{m\in\mathcal M}T_mT=maxm∈M​Tm​, the null simulation must recompute that maximum. The null model should reproduce shared errors and fitted parameters with the same fitting procedure.

This defines the object being calibrated. A selected formula cannot be treated as independently fixed merely because it can later be written without adjustable parameters. A fresh independent dataset can instead test a formula fixed before those data are examined.

A different question is a valid Monte Carlo hypothesis test. If the observed dataset and NNN null datasets produce exchangeable statistics, the rank of the observed one is uniform among N+1N+1N+1 distinct ranks. Its valid inclusive upper-tail Monte Carlo p-value is

This p-value is not the confidence upper bound above. Exchangeability must be justified; simulating from a fitted model without reproducing the fitting process does not automatically supply it.
