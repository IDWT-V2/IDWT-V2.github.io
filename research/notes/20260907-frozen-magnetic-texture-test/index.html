Summary: A frozen-protocol test admits spatial polarization textures into the existing six-dimensional magnetic kernel and treats negative energy curvature as a failure of the uniform preparation.

Frozen question

The user requested an actual attempt to falsify a consequence, without changing assumptions to protect the dimensional premise. The protocol fixes the kernel, envelope, inherited illustrative coefficients, perturbations, parameter scan, and rejection thresholds before the texture calculations. This is a model robustness test, not a blind experimental comparison.

The earlier magnetic calculation minimizes over fields at one spatially uniform spinor polarization. This test removes that uniformity restriction within a specified family, and includes the positive polarization-gradient cost. No force is added if the uniform preparation fails.

The physical electron trajectory remains a separate object: the field polarization varied here is not silently substituted for an actual orbit or interpreted as the electron's probability cloud.

Verification and model boundary

frozen_magnetic_texture_checks.py checks the protocol fingerprint, first variations, all six-direction curvatures, and direct nonlinear Fourier energies for 108 selected tangent cases at three perturbation sizes each. It also verifies the shifted angular integral independently using Cartesian Hermite and radial Laguerre quadrature. The latter converges to within 6×10−86\times10^{-8}6×10−8 of the analytic reduction on the prescribed wavelength grid.

The initial report is preserved. A subsequent check corrected the implementation of the agreement gate to use the protocol's strict absolute-plus-relative rule, without a unit-size relative-error floor; all comparisons still passed. The verified result includes that strict gate and the independent angular integration.

The analytic-supplement report adds 80 independently sampled projected-source matrix-spectrum checks and the Gaussian normalization check, for 485 runtime conditions. The theorem rests on the algebra and inequalities above, not those finite samples. Both normal and optimized-Python executions retain the runtime checks. In-memory negative controls replacing the angular response by its isotropic value or reversing the Hessian's magnetic sign were rejected by the independent integrations; neither change was saved to the model.

The regression report records all 65 selected diagnostic scripts and source checks passing before the analytic supplement's extra checks were added. The two expensive cylindrical/fixed-Casimir continuation searches were explicitly excluded. After that addition, this script passed all 485 conditions in both normal and optimized Python, and knowledge-base validation passed for all 169 notes. Diagnostic success includes correctly detecting rejected model preparations; it is not a count of successful physical predictions.

This remains a fixed-envelope, leading-order spin-magnetic reduction with a positive bare polarization-gradient cost. The minimal-coupling orbital AAA terms, electric response, radiation, profile relaxation, nuclear dynamics, and higher-order Dirac terms are not included. Strong-coupling stress failures need not lie in a controlled nonrelativistic regime. Neither the inherited illustrative benchmark nor its field-envelope scale has been justified as a physical electron parameter set.

The concrete advance is a calculable stability boundary for the existing response kernel. It is not a rejection or confirmation of the electron's spatial depth, and it does not turn the polarization field into an orbit.
