Nuclear-plane rotor

Updated September 8, 2026

Summary: A finite-inertia rank-three nuclear plane coupled reciprocally to a 6D electron preserves its projector constraints, energy, visible momentum, and combined rotational charge while undergoing nontrivial orientation response.

Purpose

The plane-response audit showed that a nuclear three-plane needs conjugate momentum. This note constructs that missing finite-inertia system before any molecular periodic orbit is sought. It is a consistency model for reciprocal orientation dynamics, not a microscopic identification of the nuclear kernel.

What this changes

The project now has an energy-conserving mechanism by which a flexible lower-depth nucleus can store orientation momentum and return it to a 6D electron. This closes the phase-space consistency gap identified in the finite-response note.

It does not yet establish gyroscopic stabilization of the trigonal saddle. The next calculation must duplicate this rotor for all symmetry-related nuclei, regularize the supported-plane Coulomb singularity using the derived finite nuclear profile, and compute the full monodromy matrix. The physical kernel must eventually determine III, ZZZ, and the finite-size profile rather than accepting diagnostic values.
