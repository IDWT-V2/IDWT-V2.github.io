Why a density interaction is different

In a quartic density interaction, the mean-field operation is

Uρ(x)=g(Tρ)(x),ψ(x)⟼Uρ(x)ψ(x), U_\rho(x)=g(T\rho)(x),\qquad \psi(x)\longmapsto U_\rho(x)\psi(x), Uρ​(x)=g(Tρ)(x),ψ(x)⟼Uρ​(x)ψ(x),

rather than ψ↦gTψ\psi\mapsto gT\psiψ↦gTψ. Squaring an odd wave function produces an even density, which can source UρU_\rhoUρ​.

For an exact example take ψ(x)=d x1\psi(x)=\sqrt d\,x_1ψ(x)=d​x1​, so ∫∣ψ∣2dσ=1\int|\psi|^2d\sigma=1∫∣ψ∣2dσ=1. Then

Thus an even kernel gives a nonzero mean-field shift to an odd state in this explicit scalar model. An even multiplication operator preserves parity; it need not annihilate the odd subspace.

Application to projected fields

Using this angular nullspace for a projected field requires an explicit identification of that field with the scalar angular functions. Physical spin-one polarization has its own representation. A mass-protection argument using the nullspace must establish that the full projected action and its corrections preserve the same structure.

The photon module instead keeps PγMPγ=0P_\gamma\mathcal M P_\gamma=0Pγ​MPγ​=0 as the condition on the full mass operator. The n=0n=0n=0 counting label alone does not prove it.

Gauge invariance supplies a different constraint. For a consistently gauged, anomaly-free quantum theory with a symmetry-preserving prescription, qμΠμν=0q_\mu\Pi^{\mu\nu}=0qμ​Πμν=0 permits nonzero transverse vacuum polarization. It does not require Πμν=0\Pi^{\mu\nu}=0Πμν=0 or a constant measured coupling. A regular transverse coefficient leaves the usual massless pole; singular terms or symmetry-breaking backgrounds require additional analysis. See Wingate's QED lectures, §6.2 for an explicit nonzero vacuum-polarization calculation.

In a simultaneous matter-and-connection gauge transformation the covariant kinetic term is invariant: the matter phase variation and connection variation cancel. On-shell current conservation and the quantum Ward identities require their respective field and measure assumptions.
