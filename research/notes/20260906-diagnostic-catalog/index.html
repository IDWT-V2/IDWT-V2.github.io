Reproduce the finite checks

From the repository root, run the registered diagnostic scripts:

python3 -B experiments/run_checks.py

For the independent audit suite without the two long continuation searches:

OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 python3 -B experiments/run_checks.py --skip-continuation --jobs 3 --report experiments/results/audit-2026-09-07/reproduction-suite.json

Exclusions are named in the output and report. The archived-state refinement test still runs; its diagnostic success does not imply candidate acceptance.

The runner uses the current Python interpreter, reports failures with nonzero exit status, and disables bytecode writes. The checks require SciPy, SymPy, mpmath, and NumPy; they do not install dependencies. electron_pair_algebra.py supplies the shared explicit Clifford construction. correction_checks_2026_09_06.py covers the normalization, topology prerequisites, action/frequency, rank-two Hessian, Clifford-commutator domain, and numerical corrections.

The original two larger audits can also be run individually from the repository root:

python3 experiments/progress_checks_2026_09_05.py
python3 experiments/ckm_count_audit_checks_2026_09_05.py

The check script uses SymPy. It checks finite algebra and comparison operators. It does not install dependencies, modify the modules, fit an amplitude, solve the V2 master equation, or predict a baryon mass.

Status vocabulary: checked algebra denotes a verified identity or spectrum for the specified operator; conditional mechanism denotes a sufficient construction whose physical premises remain unproved; source audit records what particular inspected passages say; withdrawn inference identifies an earlier conclusion that exceeded its calculation; open denotes a remaining proof obligation.
