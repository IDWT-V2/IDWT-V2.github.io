Weighted mode evaluation

Updated September 8, 2026

Why the basis values matter

Inverse simplex counts can control mode expansions when the basis values satisfy the evaluation criterion below. The reciprocal-sum identity supplies a useful bound.

For a specified scalar readout of the mode functions, write initially for finitely supported coefficients

fc(x)=∑n≥1cnϕn(x),∥c∥w2=∑n≥1wn∣cn∣2,wn>0. f_c(x)=\sum_{n\ge1}c_n\phi_n(x),\qquad \|c\|_w^2=\sum_{n\ge1}w_n|c_n|^2,\qquad w_n>0. fc​(x)=n≥1∑​cn​ϕn​(x),∥c∥w2​=n≥1∑​wn​∣cn​∣2,wn​>0.

This is a norm on coefficient sequences. Calling it a spatial L2L^2L2 norm would require an additional basis and measure identification. Its use for classical fields does not introduce any extra physical spatial dimensions.

Limits for contact calculations

V2's finite-band contact theorem uses a specified finite reproducing kernel. Passing to an infinite field requires controlling the corresponding evaluation sum and occupation weights. Derivative readouts need the sums of squared derivative values; interaction energies and determinants need their own estimates. Finite inverse-count weight alone is not a proof of universal ultraviolet control.
