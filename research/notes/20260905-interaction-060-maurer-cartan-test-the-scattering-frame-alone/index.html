60. Maurer--Cartan test: the scattering frame alone cannot generate its own restoring curvature

The strongest remaining route was to derive the missing dimensionless lock coefficient from a mixed connection constructed directly from the scattering-selected frame

Qscat(x)∈SO(3). Q_{\rm scat}(x)\in SO(3). Qscat​(x)∈SO(3).

There is an immediate canonical connection candidate,

A=dQscat QscatT \boxed{ A=dQ_{\rm scat}\,Q_{\rm scat}^T } A=dQscat​QscatT​​

or, equivalently in the left convention,

a=QscatTdQscat. a=Q_{\rm scat}^T dQ_{\rm scat}. a=QscatT​dQscat​.

Both are Lie-algebra-valued one-forms in so(3)\mathfrak{so}(3)so(3).

60.1 Exact curvature test

For the right Maurer--Cartan form,

A=dQ Q−1, A=dQ\,Q^{-1}, A=dQQ−1,

the Maurer--Cartan identity is

dA−A∧A=0. \boxed{ dA-A\wedge A=0. } dA−A∧A=0.​

For the left form,

a=Q−1dQ, a=Q^{-1}dQ, a=Q−1dQ,

one has

da+a∧a=0. \boxed{ da+a\wedge a=0. } da+a∧a=0.​

This was checked explicitly with a noncommuting two-parameter frame field

Q(x,y)=exJxeyJy, Q(x,y)=e^{xJ_x}e^{yJ_y}, Q(x,y)=exJx​eyJy​,

where [Jx,Jy]≠0[J_x,J_y]\ne0[Jx​,Jy​]=0. Both curvature tensors vanish identically.

Therefore a connection built only from the local frame map QscatQ_{\rm scat}Qscat​ is pure gauge.

60.2 Consequence for the lock mechanism

The scattering frame can still define parallel transport and angular velocity. For a one-parameter rotation

Q(t)=Rz(ωt), Q(t)=R_z(\omega t), Q(t)=Rz​(ωt),

one obtains

At=Q˙QT A_t=\dot Q Q^T At​=Q˙​QT

with

−12tr⁡(At2)=ω2. -\frac12\operatorname{tr}(A_t^2)=\omega^2. −21​tr(At2​)=ω2.

So the frame map supplies a perfectly good kinematic rate variable.

But it does not supply a preferred nonzero rate or a restoring potential. In one dimension there is no curvature two-form, and in multiple dimensions the Maurer--Cartan curvature still vanishes when the connection is constructed purely as dQ Q−1dQ\,Q^{-1}dQQ−1.

Hence

Qscat determines orientation and transport, but not a dynamical stiffness by itself. \boxed{ Q_{\rm scat}\text{ determines orientation and transport, but not a dynamical stiffness by itself.} } Qscat​ determines orientation and transport, but not a dynamical stiffness by itself.​

60.3 What would make the connection physical rather than pure gauge

A nontrivial mixed/extrinsic field must contain information beyond the frame map itself. At least one of the following is required:

  1. an independently dynamical connection whose horizontal distribution is not simply the Maurer--Cartan form of QscatQ_{\rm scat}Qscat​;
  2. a nonzero second fundamental form or projector derivative ∇P\nabla P∇P fixed by an embedding equation;
  3. coupling to another sector field whose curvature survives after choosing the scattering frame;
  4. a topologically nontrivial connection not globally representable as one smooth Q−1dQQ^{-1}dQQ−1dQ;
  5. or an induced effective action in which integrating out other fields generates a potential for QQQ.

The current V2 corpus has kinematic locations for items 1--3, but no written variational dynamics fixing their magnitude.

This rules out one tempting shortcut: the missing κ^\widehat\kappaκ cannot be obtained merely by differentiating the already constructed frame map and calling the resulting Maurer--Cartan norm a curvature eigenvalue.

The remaining viable source is a genuinely dynamical mixed/extrinsic field, projector geometry, or induced interaction whose curvature is not pure gauge.
