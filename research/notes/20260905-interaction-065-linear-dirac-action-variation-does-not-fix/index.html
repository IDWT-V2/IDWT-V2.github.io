65. Linear Dirac-action variation does not fix the projector sigma-model coefficient

Section 64 gave, under its separate-factor Clifford-commutation assumptions, the derivative identity

[D,P]=iγμ∇μP [D,P]=i\gamma^\mu\nabla_\mu P [D,P]=iγμ∇μ​P

and therefore a canonical positive quadratic norm whose Clifford trace is the Grassmannian sigma-model kinetic density.

The next question is whether the already written linear Dirac action automatically supplies that quadratic norm with fixed coefficient.

It does not.

65.1 Correct moving-subspace spectral test

Let

P(t)=R(t)P0R(t)T P(t)=R(t)P_0R(t)^T P(t)=R(t)P0​R(t)T

and transport an orthonormal basis of the selected subspace with the same rotation,

U(t)=R(t)U0. U(t)=R(t)U_0. U(t)=R(t)U0​.

The physically relevant compressed operator in the moving frame is

Heff(t)=U(t)TDU(t). H_{\rm eff}(t)=U(t)^TDU(t). Heff​(t)=U(t)TDU(t).

For

D=diag⁡(d1,d2,d3,d4) D=\operatorname{diag}(d_1,d_2,d_3,d_4) D=diag(d1​,d2​,d3​,d4​)

and simultaneous rotations 1↔31\leftrightarrow31↔3, 2↔42\leftrightarrow42↔4, direct calculation gives

Heff′′(0)=diag⁡(2(d3−d1),2(d4−d2)). H_{\rm eff}''(0) = \operatorname{diag} \left( 2(d_3-d_1), 2(d_4-d_2) \right). Heff′′​(0)=diag(2(d3​−d1​),2(d4​−d2​)).

Thus the second variation of the linear projected operator is controlled by ambient spectral gaps, not by the universal Grassmannian metric.

An earlier fixed-coordinate expectation test produced extra projector-normalization terms; transporting the selected basis removes that artifact and gives the correct gap formula above.

65.2 Scalar orientation-blind limit

If

D=mI, D=mI, D=mI,

then

Heff(t)=mI H_{\rm eff}(t)=mI Heff​(t)=mI

for every projector orientation. Hence the linear scalar Dirac term gives exactly zero frame-lock stiffness.

This is consistent with the earlier result that the scalar self-contact/rest-frequency operator does not by itself select the 3+33+33+3 orientation.

65.3 The positive commutator norm is distinct

For the same motion,

Tr⁡([D,P˙]†[D,P˙])=2[(d3−d1)2+(d4−d2)2]. \operatorname{Tr}([D,\dot P]^\dagger[D,\dot P]) = 2\left[(d_3-d_1)^2+(d_4-d_2)^2\right]. Tr([D,P˙]†[D,P˙])=2[(d3​−d1​)2+(d4​−d2​)2].

This is a positive quadratic functional of the squared spectral gaps. It is not the same as the second variation of the linear compressed operator, which is linear in the gaps.

with a fixed universal coefficient.

65.5 Status

The projector route survives, but one shortcut is ruled out:

unit normalization of the linear Dirac action does not fix the projector sigma-model normalization. \boxed{ \text{unit normalization of the linear Dirac action does not fix the projector sigma-model normalization.} } unit normalization of the linear Dirac action does not fix the projector sigma-model normalization.​

What remains viable is either:

  1. a genuine master-field quadratic commutator/projector term;
  2. a symmetry or normalization principle fixing its coefficient;
  3. or a nonperturbative relation tying the projector-gradient norm to an already derived V2 spectral ratio.
