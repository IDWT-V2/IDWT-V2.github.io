The unbiased positive response does not preserve the proposed ratios at equal norm under these source controls. Constraining the norm retains its frequency shift. The fitted common bias cancels selected first derivatives but fails the next mode and has negative response amplitude curvature. The scale-covariant response has no stable finite size by itself at any maintained depth. Thus these variants do not yet give the requested joint mass, size and support mechanism.

The nonzero background route remains algebraically possible in the angular sector because it can cancel a metric force without shifting the reference field equation. Its reported stiffness numbers are necessary lower bounds only in the stated unit-control normalization. The subsequent common-background radius calculation specifies one finite-carrier inverse action and derives its radius force, field--radius mixing and radial curvature. It leaves the angular second variation of that carrier, master-field origin and reciprocal pair response unresolved. The separate whole-depth current calculation derives its conformal Hessian from its own action and tests a wider angular basis.

The combined check initially passed 108 identities and convergence comparisons. That initial report contains every retained depth and mode; the current script also includes the later radial and conformal-current actions as separate candidates. A passing diagnostic is evidence for the stated equations, not for the physical realization of a candidate.

One quick equation comparison for the next decision

The later joint candidate script recalculates the equations needed to compare the current routes in one run. For every maintained mode at both common strength controls it places the positive-response Gram norm, linked-carrier radius pressure, whole-depth current frequency, conformal metric force, geometric Hessian and correctly normalized background threshold in one row. The depth-two current row also checks nine form-carrier zonal directions; the higher-depth rows record the pointwise coefficients that establish positive bare spinor curvature for all smooth conformal directions. Its joint report contains 32 rows and common within-depth summaries.

The two carrier actions remain separate. The linked radial threshold is reported per unit wave norm. The current model's tested conformal threshold is reported per unit phase charge and is only a lower bound for untested metric directions. The report keeps finite-strength frequency-unit spreads visible; neither carrier has an exact simplex ratio at these finite strengths. The script is a compact decision calculation, while the larger verification script retains the independent precision and quadrature tests.

The finite-chain current analysis extends that same quick calculation. It proves that both fixed positive hopping chains have a strictly decreasing frequency per simplex count as the harmonic index rises. It then checks an exact finite-band depth-two current law and a dimension-aware current correction on all maintained modes. A further inverse-depth batch tests finite branches and both shared-gap interpretations of the six-to-ten frequency unit. A component-Hessian batch retains every signed component direction under the fractional correction. Those inverse laws change the reference action, so the saturated current's conformal Hessian and support threshold do not transfer to them.
