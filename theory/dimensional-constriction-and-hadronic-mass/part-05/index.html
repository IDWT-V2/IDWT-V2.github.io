22. Minimal normal-dynamics closures

The existing V2 coordinate construction already admits a harmonic mean field

Vd(q)=λd∣q∣2. V_d(q)=\lambda_d|q|^2. Vd​(q)=λd​∣q∣2.

For the lost normal coordinate yyy in the 4→34\to34→3 transition, the minimal transverse Hamiltonian is therefore

H⊥=py22m⊥+λ4y2. H_\perp =\frac{p_y^2}{2m_\perp}+\lambda_4y^2. H⊥​=2m⊥​py2​​+λ4​y2.

Writing it in standard oscillator form,

λ4y2=12m⊥ω42y2, \lambda_4y^2 =\frac12m_\perp\omega_4^2y^2, λ4​y2=21​m⊥​ω42​y2,

gives

ω42=2λ4m⊥. \boxed{ \omega_4^2=\frac{2\lambda_4}{m_\perp}. } ω42​=m⊥​2λ4​​.​

The required pre-constriction gap is approximately

ΔE⊥=ℏω4≃232.1 MeV. \Delta E_\perp=\hbar\omega_4\simeq232.1\ {\rm MeV}. ΔE⊥​=ℏω4​≃232.1 MeV.

In natural units this requires

λ4m⊥=12(0.2321 GeV)2≃2.69×10−2 GeV2. \boxed{ \frac{\lambda_4}{m_\perp} =\frac12(0.2321\ {\rm GeV})^2 \simeq2.69\times10^{-2}\ {\rm GeV}^2. } m⊥​λ4​​=21​(0.2321 GeV)2≃2.69×10−2 GeV2.​

Thus the harmonic closure reduces the absolute hadronic-mass problem to the ratio λ4/m⊥\lambda_4/m_\perpλ4​/m⊥​.

22.3 Closure C: self-consistent nonlinear localization

Lsc=−κ42(ΨˉΨ)2. \mathcal L_{\rm sc} =-\frac{\kappa_4}{2}(\bar\Psi\Psi)^2. Lsc​=−2κ4​​(ΨˉΨ)2.

The normal-profile equation therefore contains at least one undetermined dimensional normalization even after the observed simplex mass law is imposed. The nonlinear closure cannot yet predict the transverse gap uniquely.

23. No-go for deriving the absolute gap from the present V2 action alone

The three minimal closures give the same conclusion.

  1. The harmonic kernel has the correct form but leaves λ4/m⊥\lambda_4/m_\perpλ4​/m⊥​ free.

  2. A finite-width contact generates a restoring potential but introduces an undetermined width σ\sigmaσ.

  3. A self-consistent nonlinear profile can localize the normal mode but depends on the unresolved decomposition

    μ4=κ4R4B4. \mu_4=\kappa_4R_4B_4. μ4​=κ4​R4​B4​.

Therefore the presently written V2 action does not contain enough independent information to calculate

ΔE⊥≃232 MeV \boxed{ \Delta E_\perp\simeq232\ {\rm MeV} } ΔE⊥​≃232 MeV​

from first principles.

This is not a failure of the 4/34/34/3 constriction relation. It is a parameter-counting obstruction: the theory currently fixes the combinatorial contact eigenvalue and several sector-scale products, but not the physical normal stiffness or localization width.

24. Exact missing equation

A complete V2 hadronic-mass derivation requires one additional closure equation that fixes one of the equivalent quantities

For the harmonic representation the required equation is simply

2λ4m⊥=ω42. \boxed{ \frac{2\lambda_4}{m_\perp} =\omega_4^2. } m⊥​2λ4​​=ω42​.​

The nucleon mechanism predicts that the independently derived solution must satisfy

ℏω4≈232 MeV, \boxed{ \hbar\omega_4\approx232\ {\rm MeV}, } ℏω4​≈232 MeV,​

The next mathematical target is consequently not another spectral manipulation. It is a master-geometry equation fixing the spatial normal length or harmonic stiffness. Without that equation, any absolute 232 MeV result would be fitted or reverse-engineered.

25. Dimensional-analysis closure test

The remaining possibility is that one-particle normalization of the nonlinear Dirac field might itself fix the normal localization length. It does not.

In ddd spatial dimensions, normalize a stationary one-particle profile by

∫Qd∣ψ∣2 ddx=1. \int_{Q_d}|\psi|^2\,d^dx=1. ∫Qd​​∣ψ∣2ddx=1.

[ψ]=L−d/2, [\psi]=L^{-d/2}, [ψ]=L−d/2,

∫J2 ddx∼L−d. \int J^2\,d^dx\sim L^{-d}. ∫J2ddx∼L−d.

[κd]=ELd=Ld−1 \boxed{ [\kappa_d]=E L^d=L^{d-1} } [κd​]=ELd=Ld−1​

Thus

[κ3]=L2,[κ4]=L3. [\kappa_3]=L^2, \qquad [\kappa_4]=L^3. [κ3​]=L2,[κ4​]=L3.

A normalized profile of width ℓd\ell_dℓd​ supplies a spatial overlap of schematic form

so

μd=κdRdBd \mu_d=\kappa_dR_dB_d μd​=κd​Rd​Bd​

Consequently,

This eliminates the last scale-free route from the currently written scalar self-contact to the absolute normal gap.
