From a Coulomb-bound 6D orbit with added precession to a precise rotation-and-clock model. The equations generate the ring and petals; their physical source in the electron–nucleus interaction remains to be derived.

Where the precession went

The starting proposal was an actual six-dimensional electron orbit bound by Coulomb attraction, with added precession producing the petals—not a stationary orbital or probability cloud. Earlier versions of this demo explicitly rotated the trajectory's direction and assigned a lock between the precession and orbital frequencies.

The current model gives that rotation-and-lock idea a different mathematical form. One pair of state components exchanges amplitude at rate LωL\omegaLω; another supplies an angular clock at ω\omegaω. In the chosen position readout, the angle advances while the radius contracts and expands. This produces the petals. “Amplitude exchange” describes the component equations; it does not mean that the original precession idea has been discarded.

What changed: the equations now evolve coefficients in a selected state space and map them to the displayed trajectory. This replaces the earlier rotation recipe; it is not simply the same calculation renamed, nor a numerical solution of Coulomb forces plus a derived torque. The remaining physical question is whether the coupled electron–nucleus system supplies this motion, its frequency lock, and the map to actual position. The sections below separate that question from the mathematics already specified.
